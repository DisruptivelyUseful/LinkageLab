# Solar site data

Static datasets for the Energy Zone Picker (ported from the Energy Zones project).

| File | Description |
|------|-------------|
| `ghi-grid.json` | NASA POWER annual mean GHI (kWh/m²/day), 1° grid, 2001–2020 |
| `countries-110m.json` | Natural Earth land/coastlines (TopoJSON) for the world map |

Regenerate GHI grid from the Energy Zones repo: `npm run fetch-ghi-grid`
